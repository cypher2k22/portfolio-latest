# Portfolio v2

A modern personal portfolio built with **React + TypeScript + Vite** to present my software engineering work, experience, technical skills, and selected projects.

## ✨ Sections

- Hero / introduction
- About
- Experience
- Technical skills
- Selected projects
- Contact
- Footer

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- ESLint

## 🚀 Run Locally

    git clone https://github.com/cypher2k22/portfolio-latest.git
    cd portfolio-latest
    npm install
    npm run dev

Production build:

    npm run build

Lint:

    npm run lint

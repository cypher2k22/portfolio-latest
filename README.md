## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- ESLint

## 🚀 Run Locally

    git clone https://github.com/cypher2k22/portfolio-latest.git
    cd portfolio-latest
    npm install
    npm run dev

Production build:

    npm run build

Lint:

    npm run lint
